
# ⚙️ ВПТК — калькулятор волновой передачи с телами качения

**Расчёт волнового редуктора с промежуточными телами качения (ВПТК) с минимальными габаритами. Введите любые два параметра — получите всю геометрию, моменты и готовый DXF.**

## 🚀 Возможности

| Возможность | Описание |
| --- | --- |
| **Любые 2 из 4 на входе** | Заполните ровно два поля из: передаточное число `q`, наружный диаметр `D`, момент на выходе `M_вых`, момент на входе `M_вх` — остальное считается автоматически |
| **Расчёт от нагрузки** | Диаметр тела качения `d_ТК` определяется по моменту, напряжению на срез сепаратора `[τ]`, неравномерности в ряду `k_N` и типу контакта |
| **Шарики / ролики** | Ролики дают в 2 раза больший момент при том же диаметре (≈ на 21 % меньший диаметр при том же моменте) |
| **Округление под ГОСТ** | Округляет `d_ТК` **вверх** до стандартного (шарики — ГОСТ 3722, ролики — ГОСТ 22696) и пересчитывает остальное |
| **Учёт КПД** | `M_вх = M_вых / (q·η)`, по умолчанию `η = 0.85`, можно менять; справочные значения — во всплывающей подсказке |
| **График геометрии** | Профиль жёсткого колеса, сепаратор, эксцентрик, тела качения и габарит — каждый слой включается отдельно |
| **Экспорт DXF (мм)** | Корректный `$INSUNITS = 4` — чертёж открывается в CAD в натуральную величину |
| **Экспорт PNG** | Сохранение графика в один клик |
| **Журнал расчётов** | Каждый расчёт записывается; экспорт в TXT / JSON / CSV |
| **Интерфейс RU / EN** | Язык переключается на лету, введённые значения сохраняются |
| **Проверка конструкции** | Предупреждение, если наружный радиус меньше допустимого по геометрии |
| **Полностью офлайн** | Локальный сервер только на `127.0.0.1` — данные не покидают компьютер |
| **Самостоятельный `.exe`** | Собирается через GitHub Actions, Python у пользователя не нужен |

### Границы проекта

- ✅ Подбор размеров и геометрия однорядного одноволнового ВПТК (`n = 1`, `u = 1`)
- ✅ Опора на опубликованную методику (Подшибнев, 2022)
- ❌ Это не МКЭ и не расчёт контактных напряжений — результат это отправная точка проектирования, а не заключение о прочности

## 🆚 Чем отличается от аналогов

Идея калькулятора геометрии шариковой волновой передачи вдохновлена проектом
[TrashRobotics/BallsWaveGearingGenerator](https://codeberg.org/TrashRobotics/BallsWaveGearingGenerator)
([YouTube-канал](https://www.youtube.com/@trashrobotics)). Есть и другие проекты сообщества:
[Jkl88/BallsWaveGearingGenerator](https://github.com/Jkl88/BallsWaveGearingGenerator) (интерфейс на PyQt6 поверх скрипта TrashRobotics, генерирует DXF профиля) и
[hadzaki/wave-gear](https://github.com/hadzaki/wave-gear) (визуализатор профиля на tkinter с поиском самопересечений).

Эти инструменты работают от **геометрии**: размер шарика, эксцентриситет и число впадин нужно знать заранее. ВПТК делает шаг раньше: **вы задаёте требования** (передаточное число, габарит, момент) и получаете геометрию.

| | **ВПТК (этот проект)** | hadzaki/wave-gear¹ |
| --- | --- | --- |
| Входные данные | Любые 2 из `q`, `D`, `M_вых`, `M_вх` | Ø генератора, Ø шарика, эксцентриситет, впадины, число точек |
| Подбор по нагрузке (момент → `d_ТК`) | ✅ | ❌ (расчёт напряжений в планах) |
| Прочность материала `[τ]`, `k_N`, `η` | ✅ | ❌ (КПД в планах) |
| Шарики **и** ролики | ✅ | не упоминается |
| Округление под ГОСТ | ✅ (вверх, с полным пересчётом) | ❌ |
| Выход: `D`, `L`, `W`, `z_sh`, `z_g`, `M_вх` | ✅ | только профиль |
| Слои графика | профиль, сепаратор, эксцентрик, тела качения, габарит | профиль + увеличение |
| Проверка самопересечений | ⚠ только предупреждение по радиусу | ✅ |
| DXF | `ezdxf`, единицы явно **мм**, все элементы | `dxfwrite` |
| Интерфейс | NiceGUI (локальный веб), **RU / EN** | tkinter |
| Журнал расчётов (TXT/JSON/CSV) | ✅ | ❌ |
| Распространение | `.exe` из CI как артефакт | `.exe` лежит в репозитории |
| Источник формул | Подшибнев 2022, со ссылками на формулы | общие |

<sub>¹ По README того проекта; проект Jkl88 — оболочка над скриптом TrashRobotics, его README описывает только генерацию профиля и DXF.</sub>

**Коротко:** если профиль уже известен и его нужно проверить на дефекты — подойдут визуализаторы выше. Если нужно **выбрать** передачу — какой шарик, какой наружный диаметр, какой момент она держит — используйте ВПТК.

## ⚡ Быстрый старт

### Вариант A: Windows `.exe` (Python не нужен)

1. Откройте **Actions → Build Windows EXE** (или **Releases**) и скачайте артефакт `VPTK-windows`.
2. Запустите `GeometryCalculationVPTK-v<версия>-<sha>.exe`.
3. Откроется окно консоли (в нём виден журнал, оно держит сервер) и интерфейс в браузере по умолчанию.

> 💡 Закрыть программу: кнопка **«Выход»** в интерфейсе, закрытие консоли или `Ctrl+C`. Закрытие одной вкладки браузера сервер **не** останавливает.

### Вариант B: из исходников

Нужны **Python 3.14+** и [Poetry](https://python-poetry.org/).

```bash
git clone https://github.com/<your-username>/vptk.git
cd vptk
poetry install --no-root
poetry run python main.py
```

Программа берёт первый свободный порт начиная с `8000` и сама открывает `http://127.0.0.1:<порт>`.

### Вариант C: собрать `.exe` самостоятельно

```bash
poetry install --no-root --with dev
poetry run nicegui-pack --onefile --name GeometryCalculationVPTK main.py
```

`nicegui-pack` — обёртка над PyInstaller, добавляющая статические файлы NiceGUI; без неё собранное приложение отвечает *Internal Server Error*. Флаг `--windowed` намеренно **не** используется: в консоли виден журнал.

Если в собранной версии что-то пошло не так, программа выводит окружение (версии Python и библиотек, наличие шаблонов NiceGUI) и пишет ошибки в консоль (или в `vptk.log`, если консоли нет).

## 🖥️ Использование

1. Заполните **ровно два** поля из четырёх: `q`, `D`, `M_вых`, `M_вх`.

   | Пара | Результат |
   | --- | --- |
   | `q` + `M_вых` | `d_ТК`, `D`, `L`, `W` |
   | `q` + `D` | `M_вых` |
   | `D` + `M_вых` | `q` (численно, на `q ∈ [4,1; 100]`) |
   | `q` + `M_вх` | `M_вых` через `η` |
   | `M_вх` + `M_вых` | `q` из отношения моментов; **`q` округляется до целого**, `M_вх` пересчитывается (отклонение показывается) |

2. Выберите **Шарики** или **Ролики**, при необходимости включите **«Округлить под ГОСТ»**.
3. Настройте `τ`, `k_N`, `η` (или оставьте по умолчанию: `150 МПа`, `0,56`, `0,85`).
4. Выберите элементы для отрисовки и нажмите **«Сохранить DXF»** / **«Сохранить PNG»**.
5. При необходимости сохраните журнал расчётов в TXT / JSON / CSV.

### Входные параметры

| Параметр | Обозначение | По умолчанию | Смысл |
| --- | --- | --- | --- |
| Напряжение на срез сепаратора | `[τ]` | 150 МПа | Чем больше `[τ]`, тем меньше тело качения и выше передаточное число. В подсказке — типовые стали |
| Неравномерность в ряду | `k_N` | 0,56 | Зависит от `q`: 0,50…0,56 при `q = 10…30` (Подшибнев, табл. 1.1); для грубых инженерных оценок предложено 0,6 |
| КПД | `η` | 0,85 | Эксперимент (максимум) 0,92, расчёт 0,95 (Степанов 2009); типовой диапазон 0,80…0,90. При малых моментах реальный КПД ниже (см. примечание ниже) |
| Тип тел качения | `k` | ролик | Шарик `k = 1`, ролик `k = 2` |
| Округление под ГОСТ | — | вкл | Всегда **вверх** — сохраняется запас прочности |

### Допущения

- **Один ряд** (`n = 1`, `k_H = 1`) и **одна волна** (`u = 1`) в этой версии зафиксированы — простейшая и самая распространённая конфигурация. Сами формулы поддерживают `n > 1`.
- По Степанову (2009) наружный диаметр минимален при умеренных передаточных числах; Подшибнев со ссылкой на него указывает `q ≈ 8…15`. Пульсации момента падают с ростом `q`, поэтому минимальное `q` не всегда лучший выбор.
- КПД принят постоянным. По измерениям Степанова `η(M) = 0,92·(1 − e^(−0,57·M))` (`M` в Н·м): `η ≈ 0,92` примерно от 10–20 Н·м, но заметно ниже при малых моментах — для очень малых моментов результат нужно трактовать осторожно.

## 📐 Методика расчёта

Формулы основаны на диссертации В. А. Подшибнева *«Методика проектирования исполнительного механизма привода на основе волновой передачи с телами качения с заданным уровнем виброускорения»* (2022).

Коэффициент материала (ф. 3.14, значения для сталей — табл. 3.3):

$$k_M = \frac{33{,}8\cdot 10^{3}}{[\tau]}$$

Диаметр тела качения (Подшибнев, ф. 3.15):

$$d_{ТК} = \sqrt[3]{\frac{k_M \cdot M_{вых} \cdot \sin\!\big(\pi/(q-1)\big)}{k_N \cdot k \cdot k_H \cdot n \cdot (q-1)}}$$

Габариты (ф. 3.16–3.18):

$$D = \left(\frac{2{,}06}{\sin(\pi/q)} + 1{,}8\right) d_{ТК},\qquad L = (1{,}2\,n + 1{,}8)\,d_{ТК},\qquad W = \frac{\pi}{4}D^{2}L$$

Моменты и числа элементов:

$$M_{вх} = \frac{M_{вых}}{q\,\eta},\qquad z_{sh} = \lfloor q \rfloor,\qquad z_g = z_{sh} + 1$$

Минимальный наружный радиус жёсткого колеса (для предупреждения):

$$R_{out,min} = \frac{1{,}03\, d_{ТК}}{\sin(\pi/z_g)} + 0{,}4\, d_{ТК}$$

Условие `R_out,min` обеспечивает хорду впадины не менее `2,06·d_ТК`; при его нарушении профиль жёсткого колеса получает «усы», которые нельзя изготовить, а часть тел качения теряет контакт (Степанов 2009, с. 9).

При построении профиля используются эксцентриситет `e = 0,2·d_ТК`, толщина сепаратора `h_c = 2,2·e` и радиус генератора `r_d = R_out − 2e − d_ТК`.

### Округление под ГОСТ

1. Считается точный `d_ТК`.
2. Ищется **ближайший больший** размер из стандартного ряда (шарики — ГОСТ 3722, ролики — ГОСТ 22696).
3. `D`, `L`, `W`, `M_вых`, `M_вх` пересчитываются под округлённый размер.

Округление вниз дало бы тело качения меньше расчётного; округление вверх сохраняет запас прочности. Если `d_ТК` больше максимального стандартного размера, выдаётся понятная ошибка.

### Шарики и ролики

| | Шарики (`k = 1`) | Ролики (`k = 2`) |
| --- | --- | --- |
| Контакт | Точечный | Линейный |
| Момент при том же `d_ТК` | Базовый | **В 2 раза больше** |
| `d_ТК` при том же моменте | Базовый | **≈ на 21 % меньше** |
| Износ | Выше (выкрашивание) | Ниже |
| Рекомендация | Слабонагруженные | **Силовые приводы** |

Источники: Степанов 2009 (автореферат, с. 10–11: `k_p = 2` для роликов длиной `l = d`); Подшибнев 2022, ф. 3.15.

## 📤 Экспорт DXF

Файл сохраняется в **миллиметрах** (`doc.units = MM`, `$INSUNITS = 4`). Многие генераторы единицы не указывают, и CAD может прочитать числа как метры или дюймы — здесь этого нет.

| Элемент | Объект DXF |
| --- | --- |
| Профиль жёсткого колеса | `LWPOLYLINE` |
| Сепаратор (наружный и внутренний) | 2 × `CIRCLE` |
| Эксцентрик | `CIRCLE` + `POINT` + осевая линия |
| Тела качения | `CIRCLE` на каждый элемент |
| Габарит (наружный Ø) | `CIRCLE` |

Какие элементы попадут в файл — определяют те же галочки, что и для графика.
